System Requirements

Make sure your system meets the minimum requirements

Windows

  • Windows 10 or later
  • 4GB RAM (8GB recommended)
  • 2GB free disk space
  • 64-bit processor

macOS

  • macOS 10.15 or later
  • 4GB RAM (8GB recommended)
  • 2GB free disk space
  • Intel or Apple Silicon

Linux

  • Ubuntu 18.04+ or equivalent
  • 4GB RAM (8GB recommended)
  • 2GB free disk space
  • 64-bit processor
