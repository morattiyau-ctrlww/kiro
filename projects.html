Creating New Projects

Create Project

To start coding in Kiro, first locate your project folder on your computer. You can find folders in:

  • Windows: File Explorer, Documents, or Desktop
  • macOS: Finder, Documents, or Home folder
  • Linux: File manager, home directory, or /home/username

To open folders in Kiro:

  • File > Open Folder: Browse and select your project folder
  • Drag and Drop: Drag the folder directly into Kiro IDE
  • Command Palette: Ctrl+Shift+P, type "Open Folder"

Once your folder is open in Kiro, start using vibe coding! Just describe what you want to create in plain English and let the AI assist you with code generation, completion, and smart suggestions.

Project Ideas

Try This Prompt:

build a web based pages showing my photos and some profile

This is a perfect example of how to use vibe coding with Kiro IDE! Simply type this prompt in the AI assistant, and it will help you create a personal portfolio website.

How to Use This Prompt:

  • Open a new folder in Kiro IDE for your project
  • Open the AI assistant (Ctrl+K or use the vibe coding panel)
  • Type or paste the prompt: "build a web based pages showing my photos and some profile"
  • Let the AI generate the HTML, CSS, and JavaScript structure
  • Customize and refine the generated code with your personal content

Project Organization Best Practices

Keep your projects clean and maintainable

Logical Folder Structure

Organize your files with a clear folder hierarchy that makes sense for your project type.

project/
├── src/
│   ├── components/
│   ├── styles/
│   └── scripts/
├── assets/
│   ├── images/
│   └── fonts/
└── docs/

Documentation

Keep a README.md file in your project root with setup instructions and project information.

Version Control

Initialize Git repositories for all your projects to track changes and collaborate.

Keep It Clean

Regularly clean up unused files and dependencies to keep your project organized.
