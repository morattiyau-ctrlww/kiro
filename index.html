Opening and Creating New Projects

Learn how to manage your projects efficiently in Kiro IDE

Creating New Projects

Create Project

To start coding in Kiro, first locate your project folder on your computer. You can find folders in:

  • Windows: File Explorer, Documents, or Desktop
  • macOS: Finder, Documents, or Home folder
  • Linux: File manager, home directory, or /home/username

To open folders in Kiro:

  • File > Open Folder: Browse and select your project folder
  • Drag and Drop: Drag the folder directly into Kiro IDE
  • Command Palette: Ctrl+Shift+P, type "Open Folder"

Once your folder is open in Kiro, start using vibe coding! Just describe what you want to create in plain English and let the AI assist you with code generation, completion, and smart suggestions.

Push Your Files

Push to Git

Once you've created your project, the final step is to push your files to a Git repository to deploy them to the web.

Use This Prompt:

help me push the files

What This Does:

When you use this prompt with Kiro's vibe coding, the AI assistant will help you:

  • Initialize Git repository: Set up Git tracking in your project folder
  • Add files to staging: Prepare your files for commit
  • Create commits: Save your changes with descriptive messages
  • Connect to remote: Link your local repository to GitHub/GitLab
  • Push to remote: Upload your code to trigger deployment

How Kiro Helps with Git Commands:

git init

Kiro will initialize a new Git repository in your project folder

git add .

Adds all your files to the staging area for the next commit

git commit -m "Initial commit"

Creates a commit with a descriptive message about your changes

git remote add origin [URL]

Connects your local repository to your GitHub/GitLab repository

git push -u origin main

Uploads your commits to the remote repository to trigger deployment

Benefits of Using Kiro for Git Operations:

AI-generated Git commands based on your project structure
Automatic .gitignore creation to exclude unnecessary files
Smart commit messages that describe your changes
Seamless integration with deployment platforms

3 Follow AI-generated Git commands step by step
